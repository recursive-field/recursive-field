## Constraint Shadow

- The evidence records mechanism and bounded effects, not private contents, coordinates, participant data, secret relations, or live identifiers.
- The selected project is an application scope, not a minted formation identity or canonical root.
- Deterministic precedence exists where Chapter 1 documents it, but a context-specific report of winning inputs, enabled capabilities, and applicable policy is **Not Implemented**.
- Generated model context may reflect authoritative inputs while remaining non-authoritative itself.
- No behavioral comparison establishes projection equivalence across replacement runtimes.
- Knowledge and memory freshness, coverage, retrieval quality, and isolation were not behaviorally exercised.
- A successful forward assembly does not establish reverse resolution, durable recovery, authorization, trust, or self-formation agency.

## Unresolved Questions

1. **Open — reverse resolution:** From a generated model context or runtime manifestation, what evidence can resolve back to the relevant private formation continuity without exposing private coordinates or treating the runtime as identity?
2. **Not Implemented — effective composition:** What public-safe inspection can report applicable inputs, precedence outcomes, policies, capabilities, and projection provenance for one bounded context?
3. **Open — reproducibility:** Which contextual inputs are authoritative, which are participant-scoped durable state, and which are rebuildable projections when a runtime is replaced?
4. **Open — selection versus enforcement:** Which current mechanisms merely select an input or capability, and which enforce an authority or policy boundary?
5. **Open — behavioral continuity:** How do knowledge and memory behavior affect the assembled context, and what bounded evidence would distinguish continuity from coincidental retrieval?
